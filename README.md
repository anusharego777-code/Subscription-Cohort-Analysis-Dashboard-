# Subscription Cohort Analysis Dashboard

## Project Overview
An interactive Power BI dashboard analyzing customer retention and 
subscription behaviour across 10,000+ records and 2,700+ customers.
Built to help businesses identify churn patterns and improve retention strategies.

## Tools Used
| Tool | Purpose |
|---|---|
| Power BI | Dashboard building and visualization |
| DAX | Cohort calculations and retention metrics |
| Power Query | Data cleaning and transformation |
| Excel | Data source |

## Business Questions Answered
- What percentage of customers are retained month over month?
- Which cohorts show the highest churn rates?
- How does subscription behaviour change over time?

## Key Insights
- Tracked customer retention trends across multiple subscription cohorts
- Identified months with highest churn to support retention decisions
- Built DAX measures for dynamic cohort comparisons

## Visuals Used
- Cohort matrix table
- Retention percentage heatmap
- Line charts for trend analysis
- KPI cards
